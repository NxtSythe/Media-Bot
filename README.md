# LunaMC Media Bot

بات مدیریت مدیاهای سرور: رصد لایوها و ویدیوهای یوتیوب و آپارات، ثبت‌نام خودکار مدیاها، آمار و گزارش ماهانه.

- پیام‌های بات انگلیسی هستن، فقط بخش rules فارسیه.
- همه‌ی دستورها فقط برای کسایی‌ه که رولشون پرمیشن **Administrator** داره.
- دیتابیس روی ریپوی گیت‌هاب خودت ذخیره می‌شه (رمزگذاری‌شده)، پس بات هر جا اجرا بشه اطلاعات از دست نمی‌ره.

---

## اجرا روی گیت‌هاب (بدون VPS)

> **قبلش بدون:** طبق قوانین گیت‌هاب، Actions برای کارهای غیرمرتبط با پروژه‌ی نرم‌افزاری (مثل روشن نگه داشتن یه بات) نباید استفاده بشه، و گیت‌هاب ممکنه Actions این ریپو رو غیرفعال کنه. اطلاعات از بین نمی‌ره (توی ریپو ذخیره‌ست) و می‌تونید بات رو هر جای دیگه‌ای ران کنید.
>
> بات هر **۵ ساعت و ۴۰ دقیقه** اطلاعاتش رو ذخیره می‌کنه و اجرای بعدی جاش رو می‌گیره. بین دو تا اجرا ۱ تا ۳ دقیقه آفلاینه.

### ۱. ساختن ریپو و آپلود فایل‌ها
1. توی گیت‌هاب یه ریپوی جدید بساز و **Public** انتخابش کن. ریپوی Private فقط ۲۰۰۰ دقیقه در ماه وقت داره که کافی نیست.
2. zip رو روی کامپیوترت باز کن و برو **داخل** پوشه‌ی `lunamc-media-bot`.
3. توی صفحه‌ی ریپو روی **uploading an existing file** (یا **Add file ← Upload files**) بزن و **همه‌ی محتوای داخل پوشه** رو بکش توی صفحه، از جمله پوشه‌ی `.github` و فایل `.gitignore`. بعد **Commit changes** رو بزن.
   - اگه پوشه‌ی `.github` آپلود نشد (مک فایل‌هایی که اسمشون با نقطه شروع می‌شه رو مخفی می‌کنه): **Add file ← Create new file** بزن، اسمش رو `.github/workflows/bot.yml` بذار و محتوای همین فایل رو از zip کپی کن.

### ۲. پر کردن config.yml
توی ریپو روی `config.yml` کلیک کن، دکمه‌ی مداد (Edit) رو بزن و آیدی سرور، چنل‌ها و رول‌ها رو وارد کن.
**توکن بات رو اینجا ننویس**، چون ریپو عمومیه. توکن رو توی مرحله‌ی بعد می‌ذاری.

### ۳. گذاشتن Secretها
**Settings ← Secrets and variables ← Actions ← New repository secret**:

| اسم | مقدار |
|---|---|
| `DISCORD_TOKEN` | توکن بات |
| `DB_KEY` | یه رمز طولانی دلخواه برای رمزگذاری دیتابیس. **جایی یادداشتش کن؛ اگه گمش کنی، اطلاعات دیگه باز نمی‌شه.** |
| `YOUTUBE_API_KEY` | اختیاری |
| `APARAT_PROXY` | اختیاری؛ اگه آپارات جواب نداد، یه پراکسی HTTP ایرانی |

### ۴. دسترسی Actions
**Settings ← Actions ← General**:
- **Actions permissions**: گزینه‌ی **Allow all actions** فعال باشه.
- **Workflow permissions**: **Read and write permissions** رو بزن و Save کن.

### ۵. روشن کردن
تب **Actions** ← از لیست سمت چپ **LunaMC Media Bot** ← **Run workflow** ← **Run workflow**.
بعد از ۱ تا ۲ دقیقه بات آنلاین می‌شه. از این به بعد خودش هر بار اجرای بعدی رو شروع می‌کنه.

- **دیدن لاگ:** تب Actions ← روی اجرای در حال انجام کلیک کن ← مرحله‌ی **Run the bot**.
- **خاموش کردن:** تب Actions ← **LunaMC Media Bot** ← منوی **...** ← **Disable workflow**، بعد اجرای در حال انجام رو **Cancel** کن.
- **دسترسی دادن به رفیقت:** Settings ← Collaborators ← **Add people**.

> روی اجرا (Run) و اجرای بعدی‌ای که توی صف منتظره، گیت‌هاب یه علامت زرد «waiting/pending» نشون می‌ده. این طبیعیه.
> اجراهایی هم که با وضعیت «cancelled» می‌بینی، اجراهای اضافه‌ای هستن که چون یکی دیگه توی صف بود لغو شدن. نگرانشون نباش.

## بازسازی اطلاعات قبلی
وقتی بات با دیتابیس خالی روشن بشه، **خودش** همه‌ی پیام‌های قبلیش رو می‌خونه و از روشون دیتابیس رو می‌سازه:
- از **live-history**: استریم‌ها، با مدت، تاریخ، بیشترین بیننده و وضعیت «مربوط به سرور»
- از **video-history**: ویدیوها، با ویو و مدت
- از **log**: ثبت‌نام‌ها، چنل‌ها، نوع مدیا و یوزرنیم ماینکرفت

کدهای قبلی استریم‌ها و ویدیوها حفظ می‌شن، و ویوی ویدیوها هم دوباره توی همون پیام‌های قبلی آپدیت می‌شه. نتیجه‌ی بازسازی توی چنل log میاد. اگه برای کسی چنل یا یوزرنیم ماینکرفت پیدا نشد، زیر همون پیام یه دکمه‌ی **Ask them by DM** هست که بهشون DM می‌ده تا اطلاعاتشون رو بفرستن.
اگه خواستی دوباره اجراش کنی: `/import-history`. چیزی تکراری اضافه نمی‌شه.

استریم‌ها و ویدیوهایی که وقتی بات خاموش بود رفتن، توی پیام‌ها نیستن. اینا رو با `/stats` اضافه کن.

## دستور /stats
`/stats media:` رو بزن و از لیست مدیای مورد نظر رو انتخاب کن (با یوزرنیم ماینکرفت یا اسم دیسکورد پیدا می‌شه). یه پنل باز می‌شه که این‌ها رو نشون می‌ده: آمار ماه، وضعیت هر هفته، لیست استریم‌ها و ویدیوها، چنل‌ها و یوزرنیم ماینکرفت.

دکمه‌های پنل:
- **Previous month / Next month**: رفتن به ماه قبل و بعد
- **Add / Edit / Remove stream**: اضافه، ویرایش یا حذف استریم. برای اضافه کردن، تاریخ شمسی (مثلاً `1405/08/27`)، ساعت شروع، مدت به دقیقه، بیشترین بیننده و اینکه توی آمار حساب بشه یا نه رو وارد می‌کنی.
- **Add / Edit / Remove video**: همین کارها برای ویدیوها
- **Set Minecraft username / Change type**: عوض کردن یوزرنیم ماینکرفت و نوع مدیا

همه‌ی تغییرها مستقیم توی دیتابیس و گزارش ماهانه اعمال می‌شن. موردهایی که دستی اضافه کردی با برچسب `manual` نشون داده می‌شن.

---

## بقیه‌ی دستورها
| دستور | کارش |
|---|---|
| `/media add` / `remove` / `unlink` / `list` | مدیریت مدیاها و چنل‌ها |
| `/media set-minecraft` / `remind-minecraft` | یوزرنیم ماینکرفت |
| `/media pending` / `set-related` | موردهایی که معلوم نیست مربوط به سرور بودن یا نه |
| `/report` | گزارش فعالیت ماهانه |
| `/import-history` | بازسازی اطلاعات از پیام‌های قبلی |
| `/debug aparat` | تست اتصال به آپارات |
| `/setup check` / `permissions` / `info` | تنظیمات اولیه |

## اجرا روی VPS (اگه یه روز خواستی)
روی هر سرور اوبونتو پوشه رو بذار توی `/opt/lunabot/lunamc-media-bot`، توکن رو توی `config.yml` بنویس و بزن:
```bash
cd /opt/lunabot/lunamc-media-bot && sudo bash install.sh
```
اگه می‌خوای اونجا هم دیتابیس روی گیت‌هاب ذخیره بشه، توی فایل `/etc/systemd/system/lunabot.service` زیر `[Service]` این خط‌ها رو اضافه کن و بات رو ری‌استارت کن. `GITHUB_TOKEN` یه Personal Access Token با دسترسی Contents: Read and write روی همین ریپوئه.
```
Environment=GITHUB_REPOSITORY=اسم-اکانت/اسم-ریپو
Environment=GITHUB_TOKEN=...
Environment=DB_KEY=همون رمز
```
**مهم:** بات رو هیچ‌وقت هم‌زمان هم روی گیت‌هاب و هم جای دیگه روشن نذار.
